# Velvet Vogue — Multi-page E-commerce Website

A responsive HTML/CSS/JavaScript front-end demo for the Velvet Vogue fashion store scenario.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge, or run the folder with VS Code Live Server.

## Real product photography
The product cards now use real fashion photographs hosted by Unsplash rather than illustrated SVG placeholders. The site hotlinks the image CDN URLs so an internet connection is required for the photographs to load.

## Notes
This is a coursework/demo front end. Cart, registration and admin product creation use browser localStorage; there is no real database or payment gateway.
